# Guess-no.-game-
Guess the Number Game
About the Project

Guess the Number is a simple and fun game where the player tries to guess a randomly generated number. The game provides hints to help the player figure out whether their guess is too high or too low.

I created this project to practice programming logic and improve my problem-solving skills while building an interactive game.

Features
Generates a random number for the player to guess.
Provides hints when the guess is too high or too low.
Allows the player to keep guessing until the correct number is found.
Simple and easy-to-understand gameplay.
Technologies Used
HTML
CSS
JavaScript
How to Run
Clone this repository to your computer.
Open the project folder in Visual Studio Code.
Open the index.html file in your browser.
Start guessing the number and follow the hints.

You can also use the Live Server extension in Visual Studio Code to run the game.

How to Play
Start the game.
Enter a number in the input field.
Submit your guess to check whether it is correct.
Follow the hints to make your next guess.
Continue until you find the correct number.
What I Learned

While building this project, I practiced using JavaScript to generate random numbers, handle user input, and implement conditional logic. It also helped me understand how to make a simple web application interactive.
